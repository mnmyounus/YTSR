Why it exists

Set-top boxes don't give you a record button.

YTSR runs as an Accessibility Service so it can capture globally — even while a media app is in the foreground — using MediaCodec, MediaMuxer, and AudioPlaybackCaptureConfiguration to write H.264/AAC directly to local storage.

Setup

  1. Build: ./gradlew assembleDebug
  2. Install: adb install app-debug.apk
  3. Settings → Accessibility → YTSR Key Interceptor → ON
  4. Open any TV app, double-press [0] to start recording
Known limitation

IPTV set-top boxes

  • →Persistent blank-frame captures observed on some IPTV set-top boxes. The most likely root cause is hardware overlay plane rendering on those devices — the video plane composites below what MediaProjection can capture, a hardware-level limitation rather than a bug in the recording pipeline itself.
FAQ

Common questions

Recording completes but no file appears — why?

recorder.release() must be called immediately after recorder.stop(), or the MP4 container never finalizes. Check adb logcat | grep RecordingService.

Where do recordings save?

API 29+: /sdcard/Android/data/com.younus.ytsr/files/Recordings/. API ≤28: /sdcard/Movies/YTSR/.

Why does some content record as a blank frame?

Certain IPTV set-top boxes render video through a hardware overlay plane the capture API can't see. This is a device-level limitation, not something app settings can fix.
